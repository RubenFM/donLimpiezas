# Spec Delta

## ADDED Requirements

### Requirement: Abrir un módulo desde otro

Un módulo SHALL poder abrir otro módulo, con el mismo efecto que seleccionarlo en la barra lateral.

#### Scenario: Desde Health Check
- **WHEN** el usuario pulsa "Revisar" en el apartado de actualizaciones
- **THEN** se abre Software Updater y su entrada queda marcada como activa
